# Triage labels

The Matt Pocock engineering skills use these five canonical triage roles.

| Role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer needs to evaluate the issue |
| `needs-info` | `needs-info` | The issue is waiting on the reporter |
| `ready-for-agent` | `ready-for-agent` | The issue is specified and ready for an agent |
| `ready-for-human` | `ready-for-human` | The issue requires human implementation or judgment |
| `wontfix` | `wontfix` | The project will not act on the issue |

When a skill names a triage role, apply the matching GitHub label from this table.
